# Croma

Servidor de mídia pessoal com identidade visual própria, feito sobre o Jellyfin (v12.4). Reúne filmes, séries, música, fotos, TV ao vivo e livros. O foco inicial é o desktop e a TV Samsung QN90B (Tizen 6.5).

Este repositório é o **hub** do projeto: visão geral, arquitetura e especificações. O código e a marca ficam em repositórios próprios, clonados dentro desta pasta:

| Repositório | O que é |
|---|---|
| [`croma-identidade`](https://github.com/Cintriano/croma-identidade) | Identidade visual (v0.1 "Barras" oficial) |
| [`croma-servidor`](https://github.com/Cintriano/croma-servidor) | Servidor (Jellyfin v12.4 oficial, scripts e plugins) |
| [`croma-web`](https://github.com/Cintriano/croma-web) | Interface web, compartilhada pelo desktop e pela TV |
| [`croma-desktop`](https://github.com/Cintriano/croma-desktop) | App desktop |
| [`croma-tizen`](https://github.com/Cintriano/croma-tizen) | App da TV Samsung |
| [`croma-v1`](https://github.com/Cintriano/croma-v1) | Croma v1, arquivado |

- [`CROMA.md`](CROMA.md): repositórios, versões, arquitetura, mapa do código e como clonar tudo.
- [`specs/`](specs/): especificações (coleções, tags, bibliotecas caseiras).
