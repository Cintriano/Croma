# Croma

Servidor de mídia pessoal com identidade visual própria, feito sobre o Jellyfin (v12.4). Reúne filmes, séries, música, fotos, TV ao vivo e livros. O foco inicial é o desktop (Windows) e a TV Samsung QN90B (Tizen 6.5).

- [`CROMA.md`](CROMA.md): versões, arquitetura, mapa do código e como clonar os forks do Jellyfin em `repos/`.
- [`identidade/v0.1-barras/MANUAL.md`](identidade/v0.1-barras/MANUAL.md): manual da identidade visual oficial.
- [`legado/`](legado/README.md): Croma v1, o app próprio de fotos e músicas que serviu de base. Fica só como referência, principalmente para o sistema de tags.
